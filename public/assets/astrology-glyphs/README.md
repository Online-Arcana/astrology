# Astrology SVG Pack

This archive contains a broad set of astrology-related SVGs.

## What is inside
- zodiac signs
- planets and luminaries
- nodes, asteroids, and several modern extra bodies
- aspects
- common chart-angle abbreviations
- a preview sheet and machine-readable manifest

## How the SVGs were made
Most files were generated by converting Unicode glyphs into vector outlines from installed fonts in this workspace.
Where no usable installed glyph existed, a deterministic fallback was used:
- `lot_of_fortune.svg` is a geometric approximation of U+1F774
- angle labels such as ASC, DSC, MC, and IC are vectorised abbreviations rather than single Unicode glyphs

## Structure
- `svg/zodiac/`
- `svg/planets/`
- `svg/points/`
- `svg/aspects/`
- `svg/angles/`
- `svg/misc/`

See `manifest.json` for code points, notes, and file names.
